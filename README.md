# The Thing

以**自由拼装工业机体、写实武器交战与横版机动**为目标的 Godot 2D 动作游戏原型。

> 开发中，尚未形成新机体路线下的完整战斗闭环。仓库保留早期生物拼装与纵深实验，它们不代表当前制作方向。

## 当前方向

- 完全横版 2D，使用独立部件贴图表现机体。
- 通过兼容接口装配机身、腿部、动力、控制、武器和辅助模块。
- 稳定角色控制优先，不要求机体靠真实物理承重或自行站稳。
- 目标体验：**写实的武器行为 + 清楚的战斗信息 + 有约束的自由构筑**。
- 美术方向为硬科幻工业机械与 80—90 年代日本手绘机甲动画质感。

详细方向、进度边界和建议制作顺序见 [当前策划案](docs/当前策划案.md)。[早期设计讨论稿](docs/游戏设计讨论稿.md)仅作历史参考。

## 已有原型

- 接口式自由坐标装配与装配关系校验。
- 拼装机体进入横版场景。
- 地面移动、坡面通行、走跑步态、分阶段跳跃和落地缓冲。
- 轻型姿态推进器：满足供能与质量条件后提供空中水平控制。
- 移动测试场：直道、坡面、平台、墙体及分区重生。
- 横版射击试验：瞄准、枪口位置、地形遮挡和被动靶标命中。

**尚未完成：**主动反击敌人、弹匣与装填、新路线完整胜负流程、正式损伤维修、新部件获取与改装闭环、最终美术音效。

## 运行

1. 使用 **Godot 4.7.1 stable** 打开 [project.godot](project.godot)，等待资源导入。
2. 运行项目；主入口为接口式装配界面。
3. 按 `T` 可加载“机身 + 腿”测试模板，**会替换当前界面中的装配**。
4. “出发”进入横版射击试验；“移动测试场”用于检查步态、跳跃和空中机动。
5. 姿态推进器需要额外安装动力模块，并满足当前模块承载条件；界面显示生效原因。

界面中仍保留“纵深试验”历史入口；它不是当前开发重点。

### 试验操作

- `A / D` 或方向键：左右移动；`Space`：跳跃。
- 横版射击试验：以场内提示为准，鼠标瞄准和开火。
- 移动测试场：`[` / `]` 切换区域，`R` 重生，`Esc` 返回装配。
- 横版试验镜头：按住 `Shift` 观察前方，`F2` 切换调试居中模式。

项目使用 GL Compatibility 渲染。运行原型可能写入 Godot 用户数据；不要在未备份时覆盖既有存档。

## 目录

- `scripts/assembly/`、`resources/parts/`：装配、部件与能力数据。
- `scripts/character/`：角色移动底座。
- `scripts/arena/`：横版场景、玩家、步态和射击试验。
- `scenes/prototypes/`、`scripts/prototypes/`：移动测试与历史实验。
- `art/parts/`：当前机体贴图。
- `tests/`：回归检查脚本；有测试文件不等于全部原型已经验收。
- `docs/`：设计与历史记录。

## 测试与开发边界

测试在隔离副本中运行，排除 `.git`、`.godot`、`addons`，移除副本项目设置中的 `[autoload]`、`[editor_plugins]`，避免接触真实存档。

例如在副本导入资源后执行：

```sh
godot --headless --path /path/to/isolated-copy --editor --quit
godot --headless --fixed-fps 60 --path /path/to/isolated-copy --script res://tests/assembly_check.gd --quit-after 400
godot --headless --fixed-fps 60 --path /path/to/isolated-copy --script res://tests/air_mobility_check.gd --quit-after 400
```

自动化检查只验证相应规则，不代替画面和手感验收。当前原型数值不是最终平衡承诺。
