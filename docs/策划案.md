# 机器人组装肉鸽 · 策划案

> 版本：2026-11-14
> 状态：核心玩法可运行，美术风格定型中
> 目标：横版动作 + 部件组装 + 肉鸽循环

---

## 一、一句话

**用捡来的零件拼一台歪歪扭扭的机器人，让它去打更荒唐的东西。**

黑色幽默、工业废土气质，不靠血腥，靠"丑萌 + 荒诞"。

---

## 二、核心循环

```
装配车间（拼机体）
   ↓  出发
关卡（战斗 + 搜刮零件）
   ↓  过关 / 失败
整备站（修复 + 加装）
   ↓
下一关（难度递增）
```

一局三关，数量待定。失败不掉进度，损失当关战利品。

## 三、组装系统（核心玩法）

### 3.1 基本原则

| 原则 | 说明 |
|---|---|
| **接口驱动** | 除机身高外，任何部件只能通过接口挂接，不能凭空摆放 |
| **覆盖式** | 插头与插座重合一格，靠绘制层级遮挡接缝 |
| **只有一种连接** | 接口即链路；信号与能源沿机体传导，不做单独拉线 |
| **自由坐标** | 不使用格子；格子只作为可开关的参考线与吸附辅助 |
| **单一判据** | "是不是工具""能不能放"等判断只写在数据层，UI 不重复实现 |

### 3.2 接口类型

| 类型 | 用途 | 出现位置 |
|---|---|---|
| 结构口 | 挂肢体、头壳、装甲 | 机身 |
| 工具口 | 挂末端工具（爪/锤/钻/枪） | 机械臂末端 |

### 3.3 校验规则（出发前）

| 规则 | 判据 |
|---|---|
| 结构 | 有且仅有一台机身 |
| 连接 | 所有部件都能沿父链追到机身 |
| 控制 | 有且仅有一个主控芯片 |
| 能源 | 总供能 ≥ 总耗能 |

### 3.4 操作

| 操作 | 效果 |
|---|---|
| 点部件库 / 拖出 | 手持，预览跟随鼠标 |
| 靠近接口 | 吸附并高亮，左键装上 |
| 滚轮 | 旋转预览（90°） |
| Ctrl + 滚轮 | 无极缩放 |
| 中键 / 空格拖 | 平移画布 |
| 右键部件 | 拆除该件及其子件（退款） |
| Shift + 右键 | 只拆该件，子件保留 |
| 右键工具位 | 卸下工具 |
| G / Shift + G | 参考线 / 网格吸附开关 |
| Ctrl + Z / Ctrl + Shift + Z | 撤销 / 重做 |
| 操作日志 | 收起态一行（如"12：安装 机械臂"），展开可点击回退 |

## 五、战斗与动作

| 项 | 规则 |
|---|---|
| 视角 | 侧视横版，镜头 zoom 0.6，人物固定屏幕中心 |
| 朝向 | **始终朝向鼠标**，与移动方向解耦（可倒着走） |
| 移动 | A/D，空格跳 |
| 攻击 | J 下劈 / K 突刺；动作模组驱动，从当前瞄准角发动 |
| 腿部 | 两骨 IK，落脚点驱动：脚踩世界位置，身体移动后移位超阈值才换步 |
| 伤害 | `末端伤害 × (1 + 1.2 × 速度/2500) × 质量系数` |

## 六、美术基调

| 维度 | 定值 |
|---|---|
| 参考 | 1980 年代日本硬科幻动画机械设计（《王立宇宙军》《金属外壳》） |
| 视角 | **严格正交侧视，部件一律朝右** |
| 上色 | 赛璐珞平涂 + **一道硬边阴影** + 小块硬边高光 |
| 描边 | 细线，深蓝灰，不用纯黑 |
| 结构语言 | **白色装甲板覆盖深色钢骨架**，圆形轴承座做接口 |
| 工业元素 | 液压缸、软管束、警示条、喷印编号 |
| 比例 | 小型工业步行机，紧凑但不夸张 |

### 贴图规范

| 项 | 规则 |
|---|---|
| 尺寸 | 与部件 `size` 完全一致（1:1 像素） |
| 背景 | 纯白，需去底 |
| 描边 | 内缩，不超出画布 |
| 接口处 | 贴图画基座，**代码只叠状态色**，不再画第二个盘 |

## 七、技术架构

```
scripts/assembly/    数据层（无场景依赖）
  part_data.gd       部件定义：尺寸、接口、数值
  socket_data.gd     接口：偏移、朝向、类型
  assembly.gd        树结构、吸附、增删
  rules.gd           四条校验规则（注册表）
  blueprint.gd       存档 v1
  journal.gd         操作日志 = 撤销栈
  parts_library.gd   部件库扫描 + 数据自检
  assembly_view.gd   绘制与输入
  assembly_screen.gd 拼装界面

scripts/arena/       关卡侧
  leg_ik.gd          两骨 IK
  limb_rig.gd        肢体姿态、瞄准、伤害
  slice_player.gd    玩家控制与渲染
```

**测试**：`tests/assembly_check.gd`（数据层）、`tests/screen_smoke.gd`（界面冒烟）、`tests/limb_check.gd`（肢体）
