# The Thing · 设计大纲

> 版本：0.1（概念验证阶段）
> 更新：2026-10-13

---

## 一、一句话概念

你是一只会寄生的大脑寄生虫。在安全区把捡来的器官拼装成一具宿主生物，操控它闯进关卡；
宿主会死，但你会活下来——换一具身体，继续。

## 二、核心体验

| 支柱 | 说明 |
|---|---|
| **搭积木式造物** | 不限人形。躯干、器官、肢体任意组合，唯一的约束是「它能活」 |
| **拟真生物逻辑** | 神经控制、血液供给、骨骼支撑，三条链路决定生死 |
| **肉鸽循环** | 死亡不是终点。寄生虫逃回巢穴，换具身体再战 |

**参考坐标**：《死亡细胞》的节奏与元进度 × 《坎巴拉太空计划》的组装快感

## 三、美学基调

血腥怪诞。器官是明晃晃的肉块，接口是裸露的血管和神经束。
不追求恐怖，追求**缝合怪的荒诞感**——它歪歪扭扭，但它站起来了。

## 四、核心循环

```
   ┌──────────────────────────────────────────┐
   │                                          │
   ▼                                          │
孵化池 ──▶ 拼装 ──▶ 进入区域 ──▶ 房间×N ──▶ Boss
（安全区）  器官     （俯视2D）   战斗/事件/拾取    │
            校验                        │         │
            存活                        │         │
                                        ▼         │
                                  宿主死亡/逃脱 ──┘
```

- **孵化池**：寄生虫的老巢，也是尸体库。每次 run 从这里开拼
- **拼装**：只在安全区进行，回合制、无时间压力
- **区域**：线性推进，每房间有敌人 / 事件 / 器官掉落
- **死亡**：宿主死亡 ≠ 游戏结束

## 五、拼装系统（核心玩法）

### 5.1 空间模型

- **2D 网格 7 × 5**，俯视单层平面
- 格子尺寸随窗口自适应（34–84 px），盘面始终完整可见
- **预留 3D 扩展余地**：方向枚举含「前 / 后」，格子坐标将来可加 `layer` 维度，
  校验逻辑按「允许方向集」遍历，放开方向即升级为立体，不用重写核心

### 5.2 接口系统

三类接口，用**位掩码**表示，同一方向可叠加多种：

| 接口 | 颜色 | 作用 |
|---|---|---|
| ⚡ 神经 | 青 | 传递控制信号 |
| 🩸 血流 | 红 | 供给能量 |
| 🦴 骨骼 | 白 | 物理支撑 |

方向按「**上、右、下、左**」顺时针索引（0..3）。

### 5.3 旋转

器官只定义 **0° 一套接口**，可 **90° 增量旋转**，旋转时接口循环移位：

```
joint_at(方向 d, 旋转 rot) = joints[(d - rot + 4) % 4]
```

好处：定义简单；摆位自由——腿的接口定义在「上」，转 90° 就能挂到躯干侧面。

### 5.4 操作

| 输入 | 行为 |
|---|---|
| 左键 | 在空格放置当前选中的器官 |
| 右键 | 旋转该格器官 90° |
| 中键 | 移除该格器官 |

## 六、存活校验（三条链）

拼装完成时自动校验，**三条全过才「可存活」**：

| 校验 | 路径 | 失败提示 |
|---|---|---|
| ⚡ **控制链** | 寄生虫 → 大脑 → 所有受控器官（沿神经扩散） | 有 N 个器官失去控制 |
| 🩸 **血路** | 心脏 → 所有耗血器官（沿血流扩散） | 有 N 个器官缺血 |
| 🦴 **结构** | 全部器官连成一体（任意接口都算物理连接） | 有 N 个器官孤立 |

校验通过后「出发」按钮才可用。

## 七、器官表（6 种基础）

接口记法：按「上 / 右 / 下 / 左」，⚡神经 🩸血流 🦴骨骼

| 器官 | 接口 | 特性 |
|---|---|---|
| **寄生虫** | 下：⚡ | 你的本体。控制核心，可主动脱离 |
| **大脑** | 上：⚡<br>右：⚡🩸<br>下：⚡🩸🦴<br>左：⚡🩸 | 控制中枢 + 循环枢纽 |
| **心脏** | 上：🩸　下：🩸 | 血源。自律搏动，不需要神经 |
| **腿** | 上：⚡🩸🦴 | 移动。需神经控制 + 血流供给 |
| **爪** | 上：⚡🩸🦴 | 攻击。血供越足伤害越高 |
| **脂肪** | 上：🩸　右：🦴<br>下：🩸　左：🦴 | 储能。不需神经 |

### 最小可活生物

```
   [寄生虫]
       ↓ ⚡
   [ 大 脑 ]
       ↓ 🩸
   [ 心 脏 ]
```

寄生虫 + 大脑 + 心脏 = 能动能活的最小配置。

### 设计注记

大脑左右两侧**必须带血流**（`⚡🩸`）：早期版本只有神经，
导致挂在大脑侧面的腿全部缺血——这是接口表的设计漏洞，已修正。

## 八、寄生虫与死亡

- 寄生虫**必须连上大脑**才能操控宿主
- 宿主濒死时可主动**脱离**，变成独立的慢速单位
- 脱离后可以：逃回孵化池（结束本轮）／ 寄生尸体（临时控制）
- **死亡代价分档**：
  - 逃脱成功 → 带回大部分收获
  - 寄生虫也死 → 损失更多

## 九、肉鸽结构

### 一次 run

`孵化池 → 区域（N 房间）→ Boss → 深入下一层 / 死 / 逃`

### 死亡后保留

| 类别 | 保留 | 说明 |
|---|---|---|
| **器官图纸** | ✅ 永久 | 解锁新器官种类，肉鸽核心驱动 |
| **寄生虫进化** | ✅ 永久 | 神经接口数、逃脱速度、脑容量 |
| **器官库存** | 部分 | 按逃脱成功与否带回 |
| **宿主躯体** | ❌ 清空 | 每次 run 重新拼装 |

## 十一、技术架构

### 分层原则

- **拼装界面用 `Control`，战斗表现用 `Node2D`，两者共享同一份器官数据**
  → 拼装逻辑与战斗表现解耦，改哪边都不影响另一边
- **界面 / 交互优先用引擎自带能力**：`.tscn` 搭节点树、`Theme` 资源做样式、
  `ButtonGroup` 管选中；只有算法和必要逻辑才写脚本

### 目录结构

```
res://
├── data/organs/         器官数据（规划迁到 .tres，便于做图纸解锁）
├── resources/ui/        主题与样式（main_theme.tres）
├── scenes/build/        拼装界面（build_screen.tscn / organ_tile.tscn）
├── scripts/data/        数据类（organ_data.gd / organ_library.gd）
├── scripts/build/       拼装逻辑（assembly_grid.gd / organ_tile.gd / build_screen.gd）
└── tests/               回归测试（assembly_check.gd）
```

### 已实现（原型 v0.1）

- ✅ `OrganData`：接口位掩码 + 旋转位移 + 方向工具函数
- ✅ `OrganLibrary`：6 种器官定义
- ✅ `AssemblyGrid`：自适应格子、放置 / 旋转 / 移除、三条链校验
- ✅ `BuildScreen`：完整拼装界面（引擎原生场景树 + 主题）
- ✅ `assembly_check.gd`：8 个用例的回归测试，全部通过
