# 美术基调 · 工业卡通机器人

> 本文档回答「这个资产该长什么样」。改文档要先说清楚为什么。
> 旧版（身体恐怖）已作废，生物素材留档在 `art/candidates/biobody/`。

## 1. 一句话基调

**一台用废件拼起来的次品机器人，一本正经地干活。**

黑色幽默：丑、歪、锈、贴胶带，但眼神（如果有）很认真。

## 2. 三条支柱

| # | 支柱 | 含义 | 反面 |
|---|---|---|---|
| 1 | **可读性优先** | 32px/格下能认出是臂、腿、电源还是处理器 | 细节堆到糊成一团 |
| 2 | **模块感** | 看得出这是"拼上去的"：接口、螺栓、焊缝、色差 | 浑然一体的量产机 |
| 3 | **丑萌** | 比例不对、歪一点、带点滑稽 | 精密冷硬的军用机 |

## 3. 风格坐标

| 维度 | 定值 |
|---|---|
| **总称** | **硬核机械工业风（80 年代日本手绘）** |
| **参考** | 《王立宇宙军》《金属外壳》《机动警察》——设定图级工程感 |
| **视角** | **侧视（横版），部件一律朝右**。提示词写 `side view, facing right` |
| 上色 | **平涂色块**，最多 3 档明度，**无渐变、无光泽高光** |
| 描边 | **纯黑粗描边**，硬边，不做抗锯齿 |
| 形状 | **硬边几何 + 倒角**；允许不对称，不允许圆滚滚 |
| 细节密度 | 16px 一格最多 1 层信息；螺丝不要画 |
| 情绪 | 冷硬的机器，配**一丁点**滑稽（歪一个角、补一块板） |
| 比例 | 允许夸张：大臂小身、单腿更长 |

## 4. 色彩体系

### 4.1 部件（主体）

| 用途 | 色值 | 说明 |
|---|---|---|
| 金属亮面 | `#8A929C` | 受光面 |
| 金属中调 | `#5A626C` | 主体 |
| 金属暗部 | `#2E343B` | 缝隙、内腔 |
| **强调色（唯一）** | `#F0B429` | 能源、接口、警示条——**全画面只此一个暖色** |
| 描边黑 | `#12141A` | 统一描边 |

> **纪律**：冷灰只有三档，暖色只有一个。想区分部件就改**形状**，不要加颜色。

### 4.2 场景与界面

| 用途 | 色值 | 说明 |
|---|---|---|
| 天空/远景 | `#14161C` | 近黑偏冷 |
| 地面 | `#33373F` | 冷灰 |
| 地面高光 | `#454A54` | 一档 |
| UI 面板 | `#1A181C` | 深色半透明 |
| UI 文字 | `#E6E1DC` | 偏暖白 |

**场景原则**：场景只有冷灰和近黑，**暖色（橙、红）全部留给部件和能量**。

## 5. 材质与贴图规范

| 项 | 值 |
|---|---|
| 世界换算 | **1 格 = 32 世界像素** |
| 部件贴图 | `边长 = 格数 × 32`（处理器 3×3→96，机械臂 2×5→64×160，机械腿 2×6→64×192，机身 4×6→128×192） |
| 平台贴图 | 128×128 金属板，镜像平铺 |
| 装饰 | 铆钉/焊缝用**小贴片**贴在平台上，不平铺 |

## 6. 形状语言

| 类别 | 语言 | 例 |
|---|---|---|
| 壳体/装甲 | **硬边矩形 + 切角** | 头部外壳、装甲板 |
| 关节/肢体 | **分段矩形 + 圆盘铰链** | 机械臂、机械腿 |
| 能源件 | **矩形 + 一条警示黄横带** | 电源核心 |
| 处理器 | **方板 + 侧面散热齿** | 处理器 |
| 连接 | 圆盘接口（唯一圆形元素） | 通用 |

**只有接口是圆的**，其余一律硬边——这样接口一眼就能被认出来。

## 7. 动画与表现

| 项 | 规范 |
|---|---|
| 朝向 | **始终朝向鼠标**；躯干用贴图水平翻转体现 |
| 移动 | 腿用 IK 踩地，脚不滑；离地时腿收起 |
| 攻击 | 从当前瞄准角度发动，动作模组驱动 |
| 透视 | 按 **H** 显示内部部件（外壳半透明） |
| 故障表现 | 冒火花、漏油、外壳脱落（以后） |

## 9. 决策清单

新资产按顺序问：

1. **32px 下能认出来吗**
2. **颜色在 palette 里吗**
3. **看得出是模块吗**（接口/螺栓/色差）
4. **是平涂吗**（无渐变、无光泽）
5. **好笑吗**（歪、笨、比例失调）

### 常见问题的标准答案

| 问题 | 答案 |
|---|---|
| 要不要高光？ | **不要光泽高光**，可以有平涂分色 |
| 要不要锈？ | 少量点缀可以，大面积锈会让细节糊掉 |
| 用写实还是卡通？ | **工业卡通**，比例可夸张 |
| 能量是什么颜色？ | 橙 `#E08A3C` 用于电源，蓝 `#4FB3D9` 用于信号 |
| 能不能用渐变？ | 不能 |
| 边缘怎么处理？ | 粗黑描边，不做抗锯齿 |
