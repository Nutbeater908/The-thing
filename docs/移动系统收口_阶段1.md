## 已完成

### 1. 几何层统一（`LegGeometry`）

从标定点计算：
- 大腿长度（髋→膝）：约 75px
- 小腿长度（膝→踝）：约 110px
- 脚底偏移（踝→脚底）：37px

**之前的问题**：
- 小腿用"图片高度 − 膝点 y"，算出 123px（错）
- 桥接层查固定标准腿并乘 0.86
- 拼装预览用枢轴直接加，不考虑旋转

**现在**：
- `LegGeometry.from_part()` 读标定点，计算骨长
- `compute_transforms()` 给定髋/踝世界坐标，返回三段的 position + rotation
- 拼装预览、关卡渲染、桥接高度全部共用这套计算

### 2. 桥接层高度修正

```gdscript
# 之前
leg_len = 硬编码读 leg_standard 的图片高度 * 0.86

# 现在
leg_spec = LegGeometry.from_part(实际装配的腿)
effective_height = leg_spec.total_length * standing_bend  # 0.92 可配置
```

### 3. 步态协调器骨架（`GaitController`）

双腿状态机：
- `BOTH_GROUNDED`：两脚都支撑，选较远的那只开始迈步
- `NEAR_SWING` / `FAR_SWING`：一只脚抬起，另一只支撑并跟随髋点
- `AIRBORNE`：跳跃时停止换步

射线探地：
- `_probe_ground()` 用 `PhysicsDirectSpaceState2D` 探测落脚点 y 坐标
- 不再用固定的 `hip_y + 150`

**未接入运行时**：`slice_player._animate_walk()` 调用了 `_gait.update()`，但 `LimbRig` 的 IK 驱动还未完全改造，所以腿可能不动或姿势不对。
