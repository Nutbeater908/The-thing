## 1. 核心概念

```
Body（躯干）        网格上的器官集合，提供锚点
 └ Chain（肢体链）   一串用 BONE 端口相连的 Segment
    ├ Segment 0     根节（臂），一端接躯干
    ├ Segment 1     中节（可选）
    └ Segment N     末节（末端：爪/尖刺/手）
```

- **一个 Chain 只有一个末端**（阶段 1）。分叉的链以后再说。
- Chain 的每一节有：长度、质量、关节角范围、相对父节的当前角度。
- 关卡内只渲染 Chain，不渲染网格。

## 2. 数据模型

### 2.1 OrganData 扩展

在现有字段上追加（`scripts/data/organ_data.gd`）：

```gdscript
@export_group("肢体段")
@export var segment_length := 80.0      ## 该节的长度（像素），与格子数解耦
@export var joint_min_deg := -120.0     ## 相对父节的最小角
@export var joint_max_deg := 120.0      ## 相对父节的最大角
@export var tip_damage := 0.0           ## 只有末节有效：基础伤害
@export var tip_kind: TipKind = TipKind.NONE
@export var tip_radius := 10.0          ## 末节判定圆半径
```

```gdscript
enum TipKind { NONE, CLAW, SPIKE, HAND, HAMMER }
```

现有 `limb: Limb {NONE, LEG, CLAW}` 保留，但**含义改为"这节属于哪种肢体"**，用来分组和加数值；链的合法性只看 BONE 端口。

### 2.2 OrganPort 扩展

```gdscript
@export var joint_role: int = JointRole.NONE   ## RIGID / HINGE
```

- `RIGID`：接上后角度锁死（用于躯干节之间）
- `HINGE`：可转动（用于关节）
- `NONE`：不能连肢体（普通器官）

### 2.3 新资源 LimbMotion

`scripts/data/limb_motion.gd` → `.tres`

```gdscript
class_name LimbMotion extends Resource
@export var id: StringName
@export var display_name: String
@export var trigger: int          ## 0=主攻击 1=副攻击 2=跳跃挥击
@export var duration := 0.35
@export var loop_hold := false    ## 播完是否停在最后一帧
@export var keyframes: Array[LimbKeyframe]
```

```gdscript
class_name LimbKeyframe extends Resource
@export var time := 0.0
@export var angles: Array[float]  ## 每节的目标角（度），长度 = 链节数
```

**3 个默认动作**

| id | 名称 | 用途 | 关键帧（2 节链） |
|---|---|---|---|
| `swing` | 甩击 | 臂 | 0.0:[0,0] → 0.12:[-90,-40] → 0.25:[-150,-20] |
| `thrust` | 突刺 | 臂 | 0.0:[0,0] → 0.08:[10,0] → 0.2:[60,10] |
| `stomp` | 蹬踏 | 腿（阶段 2） | 0.0:[0,0] → 0.1:[40,0] → 0.22:[0,20] |

角度按"根节→末节"排列；负数 = 朝角色面朝方向甩出。

## 3. 拼装规则

1. 躯干（寄生虫 + 脑 + 心 + 脂肪）构成 Root 格集合。
2. **臂必须从躯干格的 BONE 端口起头**，之后每节通过 BONE 端口相连。
3. 一节只能有一个父节（阶段 1 不支持分叉）。
4. 链长度限制：**2–3 节**（臂 + 末端；三节为"长臂 + 中节 + 末端"）。
5. 合法性检查进入现有的 `validation`：链断了 → 该链整条失效（不参与伤害，渲染为松弛下垂）。
6. 末端必须是 `TipKind != NONE` 的器官，否则链无效（解决"爪子单独挂着"的问题）。

## 4. 运动学模拟

### 4.1 角度驱动

```
目标角 = 动作模组当前帧插值（按 root→tip 排列）
当前角 → 目标角：临界阻尼弹簧
  ω = 20 + 30 / mass          （越重越慢）
  ζ = 0.9
```

### 4.2 关节限位

每帧把 `angle` 夹进 `[joint_min_deg, joint_max_deg]`。超限时把超出量反弹（velocity *= -0.3），做出"撞到限位"的顿感。

### 4.3 姿态求解

从躯干锚点出发，逐节累加角度：

```
p0 = 锚点
θ_i = θ_{i-1} + angle_i
p_i = p_{i-1} + Vector2(cos(θ_i), sin(θ_i)) * length_i
```

纯前向，无 IK。**末端位置 p_N 直接可得。**

### 4.4 速度

```
v_tip = (p_N(t) - p_N(t-1)) / dt
speed = v_tip.length()      # 像素/秒
```

## 5. 伤害结算

```
impact_speed = clamp(speed / ref_speed, 0, 2)          # ref_speed = 900 px/s
mass_factor  = clamp(chain_mass / ref_mass, 0.5, 2.5)  # ref_mass = 12
damage = (tip_damage + speed * 0.02) * (1 + 0.8 * impact_speed) * mass_factor
```

- 只对**敌方**生效（阶段 1 不做友伤）
- 每条链一个 0.25s 冷却，防同一帧多次触发
- 命中时给玩家一个短促的屏幕震动 + 命中停顿（0.03s 时间缩放）

**参考值**：臂 2×2（mass 4）+ 爪 2×2（mass 4）= 12 → mass_factor 1.0；甩击末端速度约 900 px/s → damage ≈ tip_damage × 1.8。

## 6. 渲染

| 阶段 | 躯干 | 肢体 |
|---|---|---|
| 阶段 1 | 现有 Polygon2D 占位 | **程序绘制**：每节画一条渐细的胶囊（`draw_line` + 圆头），末端画圆 |
| 阶段 2 | 用拼装结果生成轮廓 | 每节一张贴图，按角度旋转绘制 |
| 阶段 3 | 同上 | 关节处贴一张"关节肉瘤" |

阶段 1 的程序绘制是为了**先验证手感**，不阻塞美术。
