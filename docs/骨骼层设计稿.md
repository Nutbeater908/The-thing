# 骨骼层设计稿（第一期）

> 状态：**草案，待用户确认**。确认后才改代码。
> 目标：先跑通「脊柱 + 颅骨 + 棒骨 + 爪」这一条最小闭环。

## 1. 已定规则

| # | 规则 | 决定 |
|---|---|---|
| 1 | 骨骼之间 | **不能重叠**（同一格只能有一根骨） |
| 2 | 器官之间 | **可以重叠**，但**同类不行**（同一 id 的器官不能互相压） |
| 3 | 依附判定 | 器官的格 **重叠或边相邻** 于某根骨骼的格 |
| 4 | 接受类型 | 每根骨骼有白名单，只接受指定器官 |
| 5 | 包容特例 | **脑必须完全落在颅骨格内** |
| 6 | 脊柱承载 | 一根脊柱可被多个器官同时压着（各占不同格） |
| 7 | 依附影响数值 | **先不做** |
| 8 | 骨骼层与器官层 | 同一张网格，格可以同时有骨和器官 |

## 2. 数据模型

### 2.1 新资源 BoneData

```gdscript
class_name BoneData extends Resource

@export var id: StringName                  ## &"spine"
@export var display_name: String            ## "脊柱"
@export var color: Color
@export var texture: Texture2D              ## 留空则画色块
@export var cells: Array[Vector2i]          ## 占据的格（骨骼层，不重叠）
@export var accepts: Array[StringName]      ## 接受的器官 id 白名单
@export var containment := false            ## true = 器官必须完全在骨骼格内
@export var root_capable := false           ## true = 可以作为骨架根（只有脊柱）
@export var max_hp := 60.0                  ## 断肢用，第一期先不结算
```

### 2.2 第一期骨骼清单

| id | 名称 | cells | accepts | containment | root |
|---|---|---|---|---|---|
| `spine` | 脊柱 | 1×4 竖条 | `heart` `fat` `parasite` | false | **true** |
| `skull` | 颅骨 | 3×3 | `brain` | **true** | false |
| `rod` | 棒骨 | 1×3 竖条 | `arm` `leg` | false | false |

> **脊柱长度**：先 1×4（128px），身体总高 = 颅骨 3 + 脊柱 4 = 7 格 = **224px**。
> 如果觉得太高，改成 1×3（192px）；再高就需要重做关卡尺度。

### 2.3 骨骼之间的连接

骨骼之间**没有显式接口**，靠**格子边相邻**连成树：

```
颅骨 3×3
  └── 脊柱 1×4        （颅骨底边与脊柱顶端相邻）
        └── 棒骨 1×3   （脊柱底边与棒骨顶端相邻）
              └── 爪 2×2（爪是器官，依附在棒骨上）
```

- **根**：唯一一根 `root_capable` 的骨骼（脊柱）
- 从根做 BFS，得到骨骼树；每个骨架到脊柱的唯一路径即时肢体链
- 骨骼层内不允许重叠，所以不会出现两根骨抢同一格

## 3. 依附判定

```
for 每个器官 org:
    依附成功 = false
    for org 的每一格 c:
        for 骨骼 b:
            if 骨b 的 accepts 不含 org.id: continue
            if b.containment:
                # 包容：器官所有格都必须在 b 的格内
                if org.cells ⊆ b.cells: 依附成功
            else:
                # 支撑：重叠或边相邻即可
                if c ∈ b.cells 或 c 与 b.cells 中某格边相邻: 依附成功
    if not 依附成功: 该器官非法
```

### 具体例子

- **脑 3×3 + 颅骨 3×3**：三行三列完全重合 → 合法
- **脑 3×3 + 颅骨 3×3 偏一格**：有格超出 → **非法**
- **心脏 2×2 + 脊柱 1×4**：心脏左侧一列压在脊柱上 → 合法
- **脂肪 3×3 + 脊柱 1×4**：中间一列压在脊柱上 → 合法
- **心脏 2×2 悬空在身体右侧**：任何骨都不接触 → 非法

## 4. 校验条目（存活判定）

| 检查 | 内容 |
|---|---|
| 骨骼根 | 必须存在且唯一一根 `root_capable` |
| 骨骼连通 | 所有骨骼必须与脊柱连通（BFS 可达） |
| 器官依附 | 每个器官都必须满足第 3 节 |
| 同类互斥 | 两个相同 id 的器官格不能重叠 |
| 控制链 | 寄生虫 → 脑 → 需要神经的器官（沿用现有） |
| 血路 | 供血/需求（沿用现有） |

## 5. 拼装盘交互

| 操作 | 骨骼层 | 器官层 |
|---|---|---|
| 放置 | 只有骨骼能放；不能与已有骨骼重叠 | 只有器官能放；同类不能重叠；不要求依附（出发时才校验） |
| 拆除 | Shift+左键 | Shift+左键 |
| 旋转 | 右键 | 右键 |
| 层切换 | **Tab**（或点击"骨骼/器官"按钮） | 同左 |

**为什么放置时不强制依附**：玩家经常先摆肉再配骨，中途失败会很烦。**出发时才做完整校验**。

## 6. 渲染

| 层 | 正常 | H 透视 |
|---|---|---|
| 皮肤 | 覆盖全身 | 降到 25% 透明 |
| 器官 | **不可见** | 半透明可见 |
| 骨骼 | **不可见** | 可见（浅色骨色） |

骨骼与皮肤的关系：皮肤轮廓仍由**器官格集合**决定（现有逻辑）；骨骼不参与轮廓，只在透视时显示。
