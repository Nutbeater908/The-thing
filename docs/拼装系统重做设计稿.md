# 拼装系统重做 · 设计稿

> 状态：**设计阶段，未实现**。旧系统暂时保留可用，切换时整体替换。

## 1. 目标

| # | 目标 | 反例（旧系统的样子） |
|---|---|---|
| 1 | **一个数据模型** | 网格坐标 / 世界像素 / 渲染坐标三套并存 |
| 2 | **一种连接** | 接点拉线 + 骨骼挂点 + 工具绑定三套 |
| 3 | **规则可插拔** | 五套 `_check_*` 挤在同一个文件里 |
| 4 | **吸附放置** | 自由摆格，位置错了要到"出发"才知道 |
| 5 | **预览跟手** | 预览被锁死在格子中心 |
| 6 | **可测试** | 数据层不依赖场景，能纯脚本验证 |

非目标：不做 3D、不做多层板、不做部件内部再拆。

## 2. 数据模型

### 2.1 PartData（纯数据，`.tres`）

```gdscript
id: StringName
display_name: String
category: int          # CORE / FRAME / LOCOMOTION / TOOL / UTILITY
footprint: Vector2i    # 占几格
sockets: Array[SocketData]   # 我能接别人
plugs: Array[SocketData]     # 我能插到别人身上
mass, max_hp, power, cost
texture: Texture2D
```

### 2.2 SocketData（接口）

```gdscript
local_cell: Vector2i   # 相对部件的格坐标
kind: int              # STRUCT（结构）/ TOOL（工具口）/ SIGNAL / POWER
dir: int               # 0上 1右 2下 3左 —— 决定插头朝向
```

**规则**：插头 `plug` 与插座 `socket` 的 `kind` 必须一致，且方向相反（`plug.dir == (socket.dir + 2) % 4`）。

### 2.3 PartInstance（实例）

```gdscript
data: PartData
cell: Vector2i         # 部件原点的格坐标
rotation: int          # 0..3
hp: float
tool: PartData         # 只对 TOOL 类有效（不占格）
```

### 2.4 Link（连接）

```gdscript
from_part: int, from_socket: StringName
to_part: int,   to_plug: StringName
kind: int
```

连接是**唯一的部件间关系**。信号/能源网络由 `Link` 按 `kind` 过滤得到，不再单独存线。

## 3. 放置规则

```
1. 机身是唯一的根：第一个放下的必须是 FRAME 类、且 is_root = true
2. 其他部件只能通过 Link 挂上去，不能凭空放在空格
3. 插头格与插座格重合（覆盖式）；同格允许不同部件重叠
4. 工具（TOOL 类）不占格：选中工具 → 点带 TOOL 口的部件 → 绑定
```

### 3.1 吸附预览（关键交互）

拖拽部件时：

```
预览位置 = 鼠标世界坐标（自由跟随，不吸格）
每一帧：遍历所有未占用的 socket
        若 kind 与方向匹配，且距离 < SNAP_DISTANCE：
            把预览摆到「插头对准该 socket」的位置
            高亮该 socket
松手：有候选 → 插入；无候选 → 回到部件库
```

- `SNAP_DISTANCE` 建议 **40px**（当前缩放下约半格）
- 吸附时预览**半透明 + 接口发光**
- 右键旋转预览，旋转后重新计算候选

## 4. 校验规则注册表

每条规则一个独立函数，返回 `Check{id, label, ok, detail}`：

| 规则 | 判据 |
|---|---|
| `frame` | 有且只有一个根部件 |
| `attach` | 所有非根部件都通过 Link 连接 |
| `signal` | 主控芯片能沿 SIGNAL 连接到达每个需要信号的部件 |
| `power` | 总供能 ≥ 总耗能，且电源能沿 POWER 连接到耗能件 |
| `tool` | 带 TOOL 口的部件最多装一个工具（允许空） |
| `contain` | 需要容纳的部件（处理器）必须完全在容纳体内 |

注册方式：

```gdscript
var rules: Array[Callable] = [rule_frame, rule_attach, rule_signal, rule_power, rule_tool, rule_contain]
```

加规则 = 加一个函数 + 一行注册。

## 5. 分层

```
scripts/assembly/part_data.gd      PartData / SocketData
scripts/assembly/assembly.gd       纯数据：增删改查 + validate()
scripts/assembly/rules.gd          规则注册表
scripts/assembly/assembly_view.gd  绘制 + 输入（不持有规则）
scripts/assembly/blueprint.gd      存档 v1（带版本号）
```

`Assembly` 不引用任何 Node，可用纯脚本测试。

## 6. 交互规格

### 6.1 取件与取消

| 操作 | 结果 |
|---|---|
| 点部件库一项 | 手持（预览跟随鼠标） |
| 按住库项拖出 | 手持；**松手即尝试放置** |
| 手持 + 右键（点按拿取时） | 退回库 |
| 手持 + 松左键（拖动拿取时） | 退回库 |

两种拿取方式同时支持：**点按**适合精细放置，**拖拽**适合快速装配。

### 6.2 手持与吸附

| 操作 | 结果 |
|---|---|
| 移动鼠标 | 预览**自由跟随**，不锁格 |
| 靠近可接接口 `SNAP_DISTANCE = 40px` | 吸附到位，接口高亮，预览变为实色 |
| **滚轮** | **旋转预览 90°**（吸附重新判断） |
| 左键 | 放置；吸附失败则留在手持 |
| 距离太远时放置 | 留在手持，不丢弃 |

### 6.3 移动已放置部件

| 操作 | 结果 |
|---|---|
| 按住已放置部件拖动（> 6px） | 拆下进入手持，**子件跟随** |
| 松手且吸附成功 | 插到新位置 |
| 松手且吸附失败 | **回到原位**（不会丢件） |

### 6.4 拆除

| 操作 | 结果 |
|---|---|
| **右键** 已放置部件 | 拆除该部件**及其所有子件**，全额退款 |
| **Shift + 右键** | 只拆这一件，子件保留（会悬空，校验报错） |
| **右键** 工具位 | 卸下工具，退款 |

拆除**不弹确认**——有操作日志可以回退。

### 6.5 换件与工具

| 操作 | 结果 |
|---|---|
| 手持同类部件 → 放到已占用接口 | 旧的自动退回并退款，不弹窗 |
| 手持工具 → 点带工具口的部件 | 绑定 |
| 手持工具 → 点已装工具的部件 | 替换，旧的退款 |

### 6.6 画布

| 操作 | 结果 |
|---|---|
| 中键拖 | 平移 |
| 空格 + 左键拖 | 平移（无中键备用） |
| **Ctrl + 滚轮** | **无极缩放**（以鼠标为中心） |
| 拖动中禁止缩放 | 避免晕 |

滚轮独占给「旋转预览」，所以缩放改到 Ctrl+滚轮。

### 6.7 操作日志与撤销

日志与撤销栈**同源**：日志的每一条就是栈的一帧。

**收起态**：无底、无边框，只有一行字

```
12：已安装 机械臂
```

同时显示**步号**和**操作内容**。

**靠近**：浮现「展开」按钮。

**展开态**：有底、有窗口、有滑条，上下翻阅全部记录。

**点击某条记录**：回退到**该步之后**的状态；回退前弹**确认窗口**。

快捷键：`Ctrl+Z` 撤销一步，`Ctrl+Shift+Z` 重做。

进栈的操作：放置、拆除、换件、绑定/卸下工具、整机平移。

### 6.8 反馈

**暂不做。**早期程序化反馈（缩放弹跳、闪白、音效）会显得生硬，等美术和音效到位后再加。

## 10. 已定结论

1. 拖动已放置部件：**子件跟随**
2. 同一接口换件：**允许，旧的自动退回并退款**
3. 部件**可旋转后挂**（插头朝向随旋转变）
4. **整机可平移**（根部件换位置）
5. 缩放：**Ctrl + 滚轮，无极**
6. 拆除**不弹确认**（靠日志回退兜底）
7. 日志回退到**该步之后**
8. 日志一行：`12：已安装 机械臂`
9. 反馈：**暂不做**
