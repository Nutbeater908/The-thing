**关键设计变更**

- **去掉格子**：部件位置改为自由坐标（像素），格子只作为可开关的参考线（`G`）与吸附辅助（`Shift+G`）
- **接口驱动**：只有机身是根，其余部件必须通过 `socket ↔ anchor` 挂接
- **覆盖式**：插头与插座重合，靠绘制层级遮挡
- **单一判据**：`is_tool_part()` / `is_placeable()` / `audit()` 全工程只写一次

## 三、今日踩过的坑（避免重复）

| 问题 | 根因 |
|---|---|
| 接口始终对不齐 | 坐标换算符号反了（`逻辑 = 贴图 + tex_offset`），且显示时重复加偏移 |
| 一次保存多个接口，结果错位 | 用旧字符位置连续替换 → 改为**倒序写回** + 保存后重新解析 |
| 参照图看不见 | 被贴到画布负坐标处裁掉 → 改为**两段外接框**的大画布合成 |
| 远侧腿不显示 | `z_index = -1` 被压到地面之下 → 改用 `show_behind_parent` |
| 两条腿姿势完全一样 | 相位偏移没接到「落脚点驱动」逻辑 → 加 `_gait_bias` |
| 脚踝盘不重合 | 脚被画在 IK 终点，而不是小腿变换算出的踝点 |
| 脚掌大小缩水 | 两段各自缩放到固定宽度 → 改为**同一缩放系数** |
| 部件贴图挡住参照 | 参照图被压白底 → 保留 alpha |
