# 步态备忘

> 记录已实现与待实现的关节方案，避免以后重新推导。

## 当前方案：反关节（膝后折）

**状态**：已实现，当前使用。

| 项 | 值 |
|---|---|
| `LEG_BEND` | `-1.0`（`Limbrig` 与 `slice_player` 共用） |
| 站立高度 | `总腿长 × 0.75 + 脚掌厚度` |
| 抬脚高度 | 48px |
| 步长 | 60px |
| 单步时长 | 0.26s |
| 脚掌姿态 | 始终水平（`rotation = 0`） |
| 镜像 | 机体整体水平翻转，膝关节结构随镜像保持一致 |

**为什么用反关节**

- 重甲小腿向后折时装甲面朝外，视觉厚度正确
- 承重落在踝关节正上方，重心低，符合重型机械
- 避开"像人但又不是人"的恐怖谷

**坐标系约定**

`GaitController` 全程使用「朝向空间」：

- 原点 = 髋点
- `x > 0` = 角色前方
- `y > 0` = 向下
- 速度传入前先换算：`fwd_vel = velocity.x * facing`

镜像只作用于渲染（`LimbRig.facing` + `mirror_pivot`），不影响步态计算。

## 待实现：正关节（膝前弯）

**状态**：未实现。目前素材是反关节，正关节需要新素材或改标定。

### 与反关节的差异

| 项 | 反关节 | 正关节 |
|---|---|---|
| `LEG_BEND` | `-1.0` | `+1.0` |
| 膝关节位置 | 髋点后方 | 髋点前方 |
| 小腿方向 | 向后折 | 向前伸 |
| 脚掌 | 水平即可 | 需要踝关节大角度补偿 |

### 正关节的步态要点

1. **大腿先抬起**：摆动初期大腿向前抬（膝关节升高），小腿随后前伸
2. **脚掌滚动**：脚跟着地 → 踩平 → 脚尖蹬地离地。三段式，需要脚掌绕踝旋转
3. **身体起伏**：支撑腿直立时身体最高，双腿分开时最低（反关节也可以加，但正关节更明显）
4. **步幅比例**：约等于肩宽 × 1.5

### 需要的数据

```
pivot_ankle_roll   脚掌绕踝的旋转范围（如 -20° ~ +25°）
```

### 实现位置

- `LimbRig._draw_segments()` 里脚段的 `rotation` 从固定 `0.0` 改为按相位计算
- `GaitController` 需要额外输出"脚掌角度"字段

## 通用约定

无论正/反关节，以下不变：

1. **脚点是权威**：`_points[2]` 决定脚画在哪，`LegGeometry.transforms_from_points()` 直接用 IK 三点，不用 `compute_transforms()`（后者只有方向、丢距离）
2. **`LimbRig.externally_driven = true`**：外部驱动时 `_physics_process` 不调 `_solve()`，否则会覆盖 IK 结果
3. **支撑脚钉在世界里**：髋点移动时，支撑脚相对后移（`near_offset.x -= dx_local`），这是走路的来源
4. **静止时放下悬空腿**：`fwd_vel < 5` 时摆动腿以 4 倍速收尾落地
5. **步态与渲染分离**：步态只算偏移，渲染负责镜像和贴图变换
